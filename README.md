# Antojo CDMX

Videojuego 2D en acuarela, estilo GRIS, ambientado en la Ciudad de México. Recupera el color de la ciudad coleccionando antojitos y vence a los jefes de cada stage junto a Malvina.

Se juega directo en el navegador (computadora, iPad y iPhone): abre `index.html`.

Controles en computadora: flechas o A/D para caminar, espacio para saltar, ↓/S para agacharte, X para lanzar, C o Shift para el escudo, Esc o P para pausa y menú de controles, F pantalla completa, M sonido.
