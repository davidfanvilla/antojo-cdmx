# Antojo CDMX

Videojuego 2D en acuarela, estilo GRIS, ambientado en la Ciudad de México. Recupera el color de la ciudad coleccionando antojitos y vence a los jefes de cada stage junto a Malvina.

Se juega directo en el navegador (computadora, iPad y iPhone): abre `index.html`.

Controles en computadora: flechas o A/D para caminar, espacio para saltar, ↓/S para agacharte, X para lanzar, C (mantener) para el escudo, Esc o P para pausa y menú de controles, F pantalla completa, M sonido.

## Pantalla completa en iPhone
En Safari: botón Compartir → *Agregar a pantalla de inicio*, y abre el juego desde ese ícono. En iPad, el juego entra a pantalla completa al tocar para comenzar.

## Lotería
Termina un stage con los 14 antojitos para ganar su carta. Con las cinco, se desbloquea LA MALVINA. Se guardan en el navegador.
